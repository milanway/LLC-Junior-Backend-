# test_search_service

Тестовое. Сервис поиска по документам. FastAPI + Postgres + Elasticsearch. Всё в докере.

## Как поднять

Сначала должен быть установлен Docker Desktop. У меня на винде он без WSL не заводился, пришлось ставить wsl и ubuntu.
Файл posts.csv должен лежать в корне рядом с docker-compose.yml. Без него загрузка не сработает.

Потом в терминале:

    docker compose up --build

Первый раз минут 5-10. Качает образы, ставит питоновские пакеты. Не пугайся, что elasticsearch в логах ругается — он всегда так, потом поднимается.

Когда увидишь вот это:

    app-1  | INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

значит можно идти в браузер на http://localhost:8000/docs

## Ручки

POST /upload_data

Загружает csv. В файле должны быть колонки text, created_date, rubrics. rubrics это строка типа ['одна', 'другая'], парсится через ast.literal_eval. Кодировку определяет сам, сначала пробует utf-8, потом cp1251.
Ответ примерно такой: {"status": "ok", "loaded": 1500}
Если loaded 0 — значит колонки в csv называются не так, как я ожидал. Смотри заголовок.

GET /search?query=...

Основная ручка. Сначала идёт в elastic, находит id документов. Потом по этим id достаёт полные данные из постгреса, сортирует по created_date и отдаёт первые 20.
Почему не сортирую прямо в эластике? Потому что там для этого надо отдельно настраивать поле, а данных немного, можно и в постгресе. Для тестового норм.

DELETE /documents/{doc_id}

Удаляет из обеих баз. doc_id это целое число. Если в постгресе нет — вернёт 404. Если в эластике нет — ничего страшного, просто проглотит.

## Что я натерпелся пока делал

Клиент эластика. Если написать просто elasticsearch, pip поставит 9-ю версию, а сервер у меня 8.11.1. На старте приложения будет BadRequestError 400 при создании индекса. Поэтому в requirements.txt жёстко прописано elasticsearch[async]==8.11.1.
sqlalchemy[asyncio]. Без квадратных скобок не работает async — нужен greenlet. Я сначала не понял почему падает, думал уже на постгрес грешить.
python-multipart. Он нужен чтобы FastAPI принимал файлы через UploadFile. Без него /upload_data отдаёт 422 и ты долго думаешь что не так.
elasticsearch[async]. Тянет aiohttp. Без него падает AiohttpHttpNode при инициализации.

## Остановить

    docker compose down

Если хочется вообще всё снести с данными:

    docker compose down -v

Ключ -v удаляет волюмы. Следующий запуск будет с пустыми базами, придётся опять csv грузить.

## Если не работает

failed to connect to the docker API — Docker Desktop не запущен. Открой, дождись чтобы внизу слева стало Engine running.
Virtual Machine Platform not enabled — включаешь через dism или через компоненты винды, перезагружаешься.
WSL not installed — в повершелле от админа wsl --install -d Ubuntu, потом ребут. Дальше докер сам подхватит.
Swagger не открывается, но контейнеры вроде бегут — подожди ещё немного, uvicorn не сразу порт поднимает на первом старте.
loaded 0 при загрузке — смотри заголовки csv. Если колонки называются не text, created_date, rubrics, а как-то иначе, код их не найдёт.
